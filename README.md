# Mini Shell

A Linux-based Mini Shell implemented in C that mimics basic functionalities
of the Bash shell.

## Features

- Command prompt
- Built-in commands
- External command execution
- Command parsing
- Process creation using fork()
- Program execution using exec()
- Foreground and background process handling
- Pipe implementation
- Signal handling

## Technologies

- C
- Linux
- System Calls
- Process Management
- Signals
- IPC
- Makefile
